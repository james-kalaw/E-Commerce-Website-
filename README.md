"# E-Commerce-Website-" 
## Project Overview

Soft Where? is a front-end e-commerce website developed for ITE 011 - Introduction to Computing at the Technological Institute of the Philippines, Quezon City. The platform addresses the growing demand for licensed software by providing a secure, organized, and user-friendly marketplace where users can browse, purchase, and manage software subscriptions across five product categories.

---

## Project Objectives

- Build a fully functional e-commerce platform using HTML5 semantic elements and CSS3
- Provide users with a streamlined way to purchase licensed software applications
- Implement a responsive and modern UI with smooth animations and transitions
- Apply all three methods of CSS -- inline, internal, and external stylesheets
- Integrate JavaScript for interactive features such as modals, cart, and payment flow

## Website Pages and Features

### Home Page
- Animated marquee with promotional taglines
- Sticky navigation bar with links to all sections
- Promotional image slider with CSS-only radio button pagination
- Embedded promotional video with scroll-triggered animation
- Sign-in and Log-in button access

### Products Page
- 30 products organized across five categories:
  - Productivity and Collaboration Tools (Microsoft 365, Google Workspace, Zoom, Slack, Dropbox, Trello)
  - Creative Tools and Design Software (Adobe Creative Cloud, Canva Pro, CorelDRAW, Figma, CapCut Pro, PicsArt)
  - Media Streaming and Entertainment (Spotify, Netflix, Crunchyroll, Prime Video, Disney Plus, ESPN)
  - Cloud Storage and Antivirus Platforms (AWS, Google Cloud, Microsoft Azure, Norton, McAfee, Bitdefender)
  - E-Commerce and Website Development (Shopify, Wix Studio, BigCommerce, Squarespace, WooCommerce, Weebly)
- Product modal pop-up with image, price, description, Buy Now, and Add to Cart buttons
- Promo discount code input field

### Buying and Cart Flow
- Product modal with Buy Now and Add to Cart options
- Cart modal with item management (add and remove items)
- Proceed to Checkout redirects to payment platform selection
- Payment platform modal supporting GCash, Maya, GrabPay, PayPal, GoTyme, BDO, UnionBank, and CIMB
- Payment process modal with phone number input, amount entry, and QR code scan option
- Transaction success modal with download and subscription update options

### Sign-in and Log-in Pages
- Separate sign-up and login HTML pages with dedicated stylesheets
- Redirect to a success page upon form submission

### About Us Section
- Team profile photos with hover-to-flip name cards showing social media links
- Click-through to individual developer background pages

### Contact and Footer
- Comment and insights text area with submit button
- Social media links (Facebook, Instagram, X/Twitter, GitHub, LinkedIn)
- Links to Terms of Service, Privacy Policy, and Help Center pages
- Company email addresses

### Account Details Modal
- View account information (username, full name, bio, phone number)
- Edit profile functionality with save changes support

## Technical Highlights

- **HTML5 semantic elements** -- proper use of section, nav, footer, and article tags
- **Three CSS methods** -- external stylesheet as primary, with internal and inline CSS applied where appropriate
- **CSS animations** -- scroll-triggered animations using animation-timeline: view(), animated gradient backgrounds, marquee, and flip card effects
- **CSS-only image slider** -- built with radio buttons and label selectors, no JavaScript required
- **JavaScript modals** -- product detail, payment selection, payment process, cart, and account modals
- **Sticky navigation bar** -- stays fixed at the top during scroll with smooth anchor navigation
- **Font Awesome icons** -- used for cart, user, and social media icons
- **Google Fonts** -- Roboto and Bebas Neue for consistent typography
